# Symbols and the words they travel with

The small set of symbols. Each always travels with a word, and color is never the only signal.

- `◆` and yellow belong to approvals only. `✦` is only for new skills. `•` starts every monk message.

```text

  ✓   done · passed · recovered     ✗   failed · not now · retired    ⠹   working (spins)

  ○   not started                   ◆   needs your ok (only here)     ⚡  chaos threw a fault

  ↳   used a learned skill          ✦   new skill                     •   monk is talking

  ›   you / prompt / selected       ▣   sandbox · phone               ▌ █ streaming · caret
```
